# Highlight

Le surligneur : un aplat `signature` sous un texte `on-signature`, signature visuelle de Tracker.

Il ne sert qu'à marquer le présent : ce qui est en cours dans une phrase de synthèse, le libellé « now » de la règle, le statut running. Si deux surligneurs se disputent l'attention sur un écran, l'un des deux est de trop.

- Dans du texte courant, utilisez la version par défaut.
- Pour une donnée (`running`, `now 15:31`), utilisez `data`, en mono 11 px.
- Ne jamais l'utiliser pour mettre en valeur un mot important, une nouveauté ou une promotion.
