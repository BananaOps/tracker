# Logo

Le symbole « T surligné » et le logotype « tracker », rendus avec les tokens pour suivre le thème.

Utilisez `Logo` dans l'interface (barre latérale, écran de connexion). Pour un usage hors produit (README, slides, favicon), prenez les fichiers SVG du groupe d'assets Logos.

- `size` règle la hauteur du symbole. Le logotype suit à 78 % de cette hauteur.
- `word={false}` affiche le symbole seul, par exemple dans une barre latérale repliée.
- Le carré utilise `ink`, le fût `surface` et la barre `signature`. En thème sombre, le carré devient clair automatiquement.
- Ne pas recolorer, ne pas poser sur `signature`, ne pas descendre sous 16 px.
